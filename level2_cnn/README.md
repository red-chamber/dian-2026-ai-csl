# Level 2：CNN 完成 MNIST 并与 MLP 对比

目标：把 MLP 换成 CNN，通过**对照实验**理解卷积为什么更适合图像任务

验收标准（README.md:16）：CNN 测试集准确率约 96%，从**准确率 / 参数量 / 收敛速度 / 错误样本**四个角度与 MLP 对比

## 网络结构

```
输入                                  (N, 1, 28, 28)
  Conv2d(1, 32, 3, padding=1) + ReLU  (N, 32, 28, 28)
  MaxPool2d(2)                        (N, 32, 14, 14)
  Conv2d(32, 64, 3, padding=1) + ReLU (N, 64, 14, 14)
  MaxPool2d(2)                        (N, 64, 7, 7)
  Flatten                             (N, 3136)
  Dropout
  Linear(3136, 32) + ReLU             (N, 32)
  Dropout
  Linear(32, 10)                      (N, 10)   logits
```

| 层 | 配置 | 参数量 |
|---|---|---|
| 卷积 1 | `Conv2d(1, 32, 3, padding=1)` + ReLU + MaxPool | 1×32×3×3 + 32 = 320 |
| 卷积 2 | `Conv2d(32, 64, 3, padding=1)` + ReLU + MaxPool | 32×64×3×3 + 64 = 18,496 |
| 全连接 1 | `Linear(3136, 32)` | 3136×32 + 32 = 100,384 |
| 全连接 2 | `Linear(32, 10)` | 32×10 + 10 = 330 |
| **合计** | | **119,530** |

> **参数量的大头在展平后的全连接层，不在卷积层。**
> 两层卷积合计只有 18,816 个参数，而 `Linear(3136, 32)` 一层就占 100,384 —— 整网的 84%。
> 这也是为什么第一个全连接层只取 32 维：若取 128 维，这一层就是 401,536，整网涨到 42 万，和 MLP 几乎持平，
> 「CNN 用更少参数达到更高准确率」这个结论就看不出来了。
>
> 顺带引出 Level 3 的伏笔：**VGG 用全局平均池化替掉这个全连接层**，正是为了消掉这个参数大头。

### 为什么 `padding=1`

`kernel_size=3` 配 `padding=1` 时卷积**不改变边长**（same padding），边长只由池化减半，形状变化干净好推：

```
28 --conv--> 28 --pool--> 14 --conv--> 14 --pool--> 7
```

如果不加 padding，会变成 `28→26→13→11→5`，既丢掉了边缘信息，形状也不好记。

### 为什么输出层同样不加 softmax

和 Level 1 一致：损失函数是 `nn.CrossEntropyLoss`，内部已经等价于 `log_softmax + NLLLoss`。

## 卷积为什么更适合图像（原理）

这是 Level 2 真正要回答的问题，四个角度都是它的证据。机制上有四点：

1. **局部连接**
   MLP 的第一层是 `Linear(784, 512)`，每个神经元都连着全部 784 个像素，参数量 40 万。
   CNN 的 `Conv2d(1, 32, 3)` 只看 3×3 的邻域，参数量 320。
   图像的相关性本来就是局部的（相邻像素才相关），全连接是把这种先验丢掉、再从数据里重新学一遍。

2. **权值共享**
   同一个 3×3 卷积核在整张图上滑动，参数在所有位置复用。
   所以「检测某个笔画」这件事只需要学一次，而不是在每个位置各学一套。
   这是 CNN 参数量能压到 MLP 五分之一的直接原因。

3. **平移等变性**
   权值共享的副产品：数字「7」出现在左上角还是右下角，卷积核的响应只是跟着移动位置，特征本身不变。
   MLP 做不到这点 —— 它在每个位置都有独立权重，图一平移就是完全不同的输入模式。

4. **层次化特征**
   两层卷积堆叠 + 池化，感受野逐层扩大（3×3 → 5×5 → …）。
   浅层学到边缘/笔画，深层组合成部件，最后全连接层再做分类。
   MLP 只有「像素 → 全连接」一级，中间没有这种结构化的抽象。

一句话：**MLP 把图像当成一串无序的像素值，CNN 把图像当成二维的、有局部相关性的信号。**
MNIST 上这个差距还不算悬殊（MLP 也能过 98%），到 Level 4 的文档图像擦除任务上，
输入尺寸和结构复杂度一上来，全连接的做法就完全不可行了。
